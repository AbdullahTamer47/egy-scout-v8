> انسخ الملف ده في `D:\manger\docs\AGENT_BRIEF_V11.md` وخلّي الـ Agent يقراه قبل أي شغل.

## 0. قواعد الشغل (إلزامية)

1. **ممنوع تعدّل أي سطر كود** قبل ما تخلّص المرحلة A (الفحص)، وتكتب النتيجة في `docs/AUDIT_V9_5.md`، وأوافق عليها.
2. كل بند في الخطة جاي من قراءة **الدليل** مش من الكود. ممكن يطلع غلط أو متصلّح. ما يتنفذش غير اللي اتأكد بدليل (`ملف:سطر` أو نتيجة تشغيل فعلية).
3. استخدم المهارات الموجودة في `D:\manger\.agents\skills\`:
   - `systematic-debugging` قبل أي إصلاح.
   - `test-driven-development` لكل ميزة.
   - `verification-before-completion` قبل ما تقول "خلص".
   - `ecc-security-review` لأي حاجة فيها صلاحيات أو API أو مدخلات خارجية.
   - `football-data-integrity` لأي اسم لاعب أو مركز.
4. تغيير صغير = commit مستقل + اختبار. ممنوع refactor كبير مخلوط مع ميزة.
5. **ما تخترعش بيانات**: أسماء لاعبين، أرقام قمصان، أبعاد ملاعب، أسماء موديلات AI. كله من ملف مصدر أو API حي ومعاه `source` و`verified_at`. لو مش متأكد، اسأل.
6. بعد كل مهمة اكتب تقرير 5 أسطر: اتغير إيه، الاختبار اللي أثبت، وإيه اللي لسه مش متأكد منه.
7. البيئة Windows + PowerShell. ما تفترضش Docker ولا خدمات مدفوعة. المبدأ: **مجاني ومحلي أولًا**.

## 1. السياق

- **Backend:** FastAPI على 8080 — `apps/api/main.py`, `routes_pro.py`, `service.py`.
- **Frontend:** Next.js على 3000 — `apps/web/src/` (أهم الملفات: `BroadcastStudioScreen.tsx`, `FormationBlueprintBoard.tsx`, `TacticalTwinCanvas.tsx`, `ThreePitchTwin.tsx`, `FairScoutingScreen.tsx`, `QuickAnalysisScreen.tsx`, `AccuracyProofScreen.tsx`, `TacticalAIChatbot.tsx`).
- **المحركات:** `packages/tactics_engine` (xG, event_models), `packages/scouting_core` (fair_engine), `packages/shared_contracts`.
- **الرؤية الحاسوبية:** `services/cv_worker` (YOLO 4 فئات، `one_euro.py`, `local_pipeline.py`).
- **التخزين:** SQLite + Parquet في `D:\egy-scout-data`. **الأدوات:** ffmpeg, yt-dlp, Groq (LLM).
- **الاختبارات الحالية:** `tests/test_waves_1_to_5.py`.
- **المستخدم المستهدف:** أكاديميات وأندية في مصر، تشغيل محلي على ويندوز.

## 5. قرارات لازم تتاخد مني (ما تفترضهاش)

1. المستخدم الأساسي: أكاديميات ناشئين ولا أندية محترفة؟
2. التشغيل على جهاز واحد ولا أكتر من جهاز على نفس الشبكة؟
3. فيه GPU؟ ومواصفات أضعف جهاز لازم يشتغل عليه؟
4. إرسال بيانات الناشئين لـ Groq (سحابي) مقبول، ولا نضيف موديل محلي؟
5. ترخيص موديل YOLO وحقوق الفيديوهات: مين يراجعهم؟
6. المصدر المعتمد لقوائم اللاعبين (ملف من النادي؟ لصق؟).
7. هل قيد "مجاني ومحلي أولًا" لسه ثابت؟
