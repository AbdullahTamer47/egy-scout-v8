# EGY-SCOUT Coach Pro (`نسخة المدرب والمدير الفني والإداري`)

تطبيق تشغيلي منفصل ومستقر مبني على الأسس التكتيكية والرياضية لـ **EGY-SCOUT** بدون أي أخطاء تتبع فيديو أو تخمين، ومصمم يومياً للجهاز الفني والإداري:

## ما يقدمه Coach Pro (`/coach`)
1. **بوابة دخول وإعداد المدرب (`CoachOnboardingGate`):** يكتب المدرب اسمه ومنصبه، ويختار فريقه وفريق الخصم من قاعدة بيانات **جميع أندية الدوري المصري الممتاز (23 نادياً وأكثر من 690 لاعباً حقيقياً)** أو من الدوريات العالمية الحية.
2. **الخطط والتكتيك + معمل الكرات الثابتة (`CoachTacticsStudio`):** تطبيق خطط متقدمة (4-2-3-1 / 3-4-2-1 تشابي ألونسو / 3-2-4-1 جوارديولا / 4-3-3 كلوب / 3-5-2 إنزاجي أو أي خطة مخصصة) على اللاعبين الجاهزين فقط، مع محاكاة 9,600 ركنية.
3. **الوحدات التدريبية والأحمال (`TrainingSessionStudio`):** تقسيم الأسبوع العلمي (`MD-5` إلى `MD+1`) وحساب `sRPE (AU)` + سبورة ملعب تفاعلية لتمارين `UEFA Pro` مع الطباعة الفورية.
4. **المدير الفني وعمق القائمة (`TechnicalDirectorHub`):** خريطة الـ 11 مركزاً، تنبيهات النقص العددي، استعراض كامل لاعبي الفريقين بتفاصيلهم وصورهم، والمقارنة الحية بجدول الدوري.
5. **الإداري وكشف المباراة (`TeamAdminHub`):** السجل الطبي والإنذارات (استبعاد تلقائي عند 3 بطاقات صفراء أو الإصابة) وتوليد كشف المباراة الرسمي للـ 20 لاعباً والطباعة.
6. **المساعد الذكي الرئيسي (`CoachAICopilot`):** شات بوت ذكي متصل حياً بقائمة الفريقين والإصابات والترتيب الحي وينفذ الخطط والتمارين وكشف المباراة مباشرةً.

## وضع النسختين (Dual Edition)
- **نسخة المدرب المعتمدة (Production):** `http://127.0.0.1:3000/coach` — مستقرة وبيانات حية ومضمونة 100% (التشغيل المباشر: `start_coach_pro.bat`).
- **النسخة الكاملة شامل تحليل الفيديو (`Beta`):** `http://127.0.0.1:3000/` — تتضمن استوديو بث الفيديو والتحليل البصري التجريبي.

> **ملاحظة الفيديوهات:** خطة الفيديوهات الموشن جرافيك مؤجلة بالكامل لحين طلبك، وستشمل 4 فيديوهات (2 عربي/إنجليزي لنسخة المدرب Coach Pro + 2 عربي/إنجليزي للنسخة الكاملة Beta).
